# VisionWorkbench License Issuer

独立的离线许可证发放工具。该项目不引用 `VisionWorkbench` 主程序项目，仅按照双方约定的 JSON + ECDSA P-256 协议生成许可证。

## 使用流程

1. 首次生成时，工具会在当前 Windows 用户的本地应用数据目录自动生成签发私钥，并保存对应公钥。
2. 将公钥配置到 VisionWorkbench 客户端的 `LicensePublicKey`。
3. 客户在客户端“许可证管理”中复制完整申请码并发送给授权方。
4. 在本工具粘贴申请码，选择“一天、一周、一月、一年、三年、十年”或“永久”。
5. 点击“生成许可证”。许可证会自动保存到本地授权目录。
6. 将生成的 `.vwlicense` 文件交给客户；私钥不得进入客户端、安装包或代码仓库。

签发数据目录：`%LOCALAPPDATA%\VisionWorkbenchLicenseIssuer`；许可证默认输出目录：`D:\` 根目录。没有 D 盘时回退到签发数据目录。

许可证文件中的签名覆盖完整载荷。客户修改客户名、设备码、有效期或功能后，客户端签名校验会失败。
